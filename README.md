# Sweetheart · DEAREST

一份只属于你的浪漫。奶油色信纸、玫瑰插画与酒红色封蜡，包含拆信、开盒、花瓣动画及礼物领取卡。

网站：https://nanxiang-git.github.io/Sweetheart/

## 使用

- 打开 index.html 或访问上方网站。无需构建或安装依赖。
- dearest.html 是图片、样式和脚本均内嵌的独立版本，下载后可直接打开。
- 昵称、落款与领取说明在 index.html 中替换。
- 淘宝链接、兑换码和淘口令在 script.js 顶部 GIFT 中填写；占位状态下不会跳转或复制虚假信息。
- 背景音乐标注为林俊杰《冻结》，未附带歌曲音源。点击右上角按钮，选择自己有权使用的音频，仅本机播放，不上传。
- 礼物参考图片由用户提供；装饰为 SVG 与 CSS。Google Fonts 不可用时自动使用系统字体。

修改分文件版本后，需要同步更新独立版本 dearest.html。
